# 📊 Amazon Sales & Inventory Analytics Dashboard  
**A Streamlit-based analytics platform for Sales, Customer, Product, and Inventory Insights**

---

## 🚀 Overview  
This project is an end-to-end **Data Analytics Dashboard** built using **Python, Pandas, Streamlit, Excel, and Matplotlib**.  
It enables businesses to track sales performance, customer behavior, product trends, and inventory health through clear, interactive visualizations.

The dashboard solves three core business problems:  
- Lack of unified visibility across sales & inventory data  
- Manual and repetitive reporting  
- Difficulty predicting stock risks (low-stock, overstock, returns)

---

## 🧠 Key Features  
### 🔹 Sales Analytics  
- Daily/Monthly sales trends  
- Category & product performance  
- Revenue breakdowns  
- High-return products  

### 🔹 Customer Insights  
- Customer order trends  
- Purchase patterns  
- Repeat vs new customers  

### 🔹 Inventory Analytics  
- Stock forecasting  
- Overstock detection  
- Low-stock alerts  
- Reorder recommendations  

### 🔹 Product Performance  
- Best / worst-selling items  
- Price–volume analysis  
- Heatmaps (optional depending on data)

⚙️ How to Run the Project
1. Clone the Repository
git clone https://github.com/your-username/Amazon-Sales-Inventory-Analytics-Dashboard.git
cd Amazon-Sales-Inventory-Analytics-Dashboard

2. Install Dependencies
pip install -r requirements.txt

3. Launch the Dashboard
streamlit run app.py
